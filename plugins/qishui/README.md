# 汽水音乐匿名整曲插件

源码位于 `src/index.js`，在上级目录运行 `npm run build` 生成 `dist/plugin.js`。运行时只使用 MusicFree 内置 Axios，不需要账号、Cookie、自建服务或签名器。

## 功能

- 匿名歌曲搜索与游标分页。后续页必须原样续传服务端 `search_params`，单独传 `offset` 或 `real_offset` 会重复第一页。每次新搜索重新取得游标，只保留当前关键词的分页会话。
- 歌曲详情、封面及原生歌词。歌词不存在时返回无歌词，不生成或匹配其他版本歌词；当前不提供翻译。
- 单曲导入支持十进制字符串歌曲 ID，以及 `https://music.douyin.com/qishui/song/歌曲ID` 完整链接。短链接需先展开。19 位 ID 始终按字符串处理，不转换为 JavaScript Number。
- 标准音源优先使用平台 `medium` 档，无该档时取返回的最低码率流。

## 完整播放判定

从 `beta-luna.douyin.com/luna/h5/seo_track` 获取曲目与流信息，核对曲目 ID，比较歌曲毫秒时长与流秒数。两者必须有效且差值不超过一秒。时长不完整、音源缺失、身份不符或带有明确加密标记时抛出错误，不能作为完整歌曲播放。

`gear_des_key` 也存在于实测的普通 AAC 音轨中，不能单独作为音频加密依据。联网测试另外读取免费样本的 MP4 `moov`／`mvhd`，确认实际容器时长与普通 AAC 音轨，检查加密标记；这些样本验证不代表所有歌曲均可匿名播放。

免费样本 `7543643914910517290` 的实测容器时长为 210.164 秒，支持 HTTP 206；受限样本 `7501674235158431760` 为 236.620 秒歌曲，仅返回 60.001 秒试听，插件拒绝播放。有词样本仍可独立获取歌词。

接口与字段依据：[可读 MusicFree 参考](https://github.com/qwerwhr/musicfree-plugins) 、[SEO 路线排障记录](https://github.com/XxHuberrr/Mineradio-paused/issues/452) ，以及实际匿名响应。未执行第三方插件，不调用其已失效的播放／解密服务。

本插件不支持登录、会员歌曲解锁、音频解密、歌单导入或多音质。完整验证命令和统一订阅说明见上级 `README.md`。
