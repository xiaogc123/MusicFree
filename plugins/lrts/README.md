# 懒人听书书籍适配（播放受登录限制）

已实现书籍专辑搜索、完整章节目录、章节详情和标准音源请求适配。目录每页 50 章，无固定章节上限，校验总数、连续章节序号、字符串资源 ID 唯一性，结束前复核首批目录及总数；失败不返回部分章节。

官网数字章节 `id` 实测超过安全整数范围且已发生舍入，使用 `书籍ID:章节序号` 作为主键，播放使用字符串 `sectionId`，不将失真的数字 ID 转为字符串冒充正确值。

当前官网 `getListenPath` 对免费样本明确返回状态 485「需要登录」，搜索也可能要求登录。因此本插件只保留本地产物及回归测试，**未列入可用订阅，匿名播放未完成验收**。不提供账号、Cookie 配置或登录绕过。付费、试听与无法确认完整时长的响应均失败。无原生歌词，返回 `null`。

实测书籍 `91598933` 完整读取 42 章，播放请求被登录限制；离线覆盖 1203 章跨批次、缺章、重复、后续宿主页终止和大整数身份。真实 Axios／Android 端内均待验收。

当前接口和参数逐字段对照官网书籍页、搜索页及其公开脚本；早期 [可读参考](https://github.com/yoval/lrts/blob/master/lrts.py) 使用的播放接口已过时，未照搬其登录或下载逻辑。临时页面及响应保存在已忽略的 `tmp/audiobook-research/`。

源码 `src/index.js`，独立产物 `dist/plugin.js`，使用上级构建与 `test:audiobooks` 验证。后续接入需要另行确认登录方案，并重新核对官网协议与播放权限。
