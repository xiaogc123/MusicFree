# 喜马拉雅公开有声书插件

在 MusicFree 中选择本插件的「专辑」搜索，输入书名或主播名，打开结果查看章节。每章保留独立 ID、标题、主播、封面与秒制时长，按平台目录顺序排列。

目录逐页读取，每页 100 章，无固定 500／1000 章截断；校验声明总数、实际数量、唯一 ID、连续顺序和书籍归属，结束前复核首批目录身份、标题及总数。缺章、目录变化或任意请求失败时整次失败，不返回部分列表。持续更新的书籍可能需要重新搜索再打开。完整性以平台公开返回的目录为准，末次复核不能保证读取期间中间章节从未变化。

只接受匿名公开章节的明文 HTTP／HTTPS 音源，不解密付费播放信息。付费、优先听、试听标记或时长不一致会报错；列表保留受限章节，不保证每章能匿名播放。无原生歌词，`getLyric` 返回 `null`，不把简介作为歌词。

联网验证：书籍 `11008436` 完整读取 417 章，末章 `1025833991` 详情身份一致；首章音频 HTTP 206，文件容器实际 168.508 秒，与接口 168 秒一致。验证使用 Fetch HTTP 适配器，Android、Hermes、宿主 Axios、原生播放未验收。

源码 `src/index.js`，独立产物 `dist/plugin.js`，由上级构建生成。命令：`npm --prefix plugins run build`、`npm --prefix plugins test`、`npm --prefix plugins run test:audiobooks`。

断点续听、自动下一章和定时停止由宿主处理，本插件不修改播放器。有声书已加入本地统一订阅，推送前线上订阅保持旧内容。

接口参考：[可读开源实现](https://github.com/CharlesPikachu/musicdl/blob/master/musicdl/modules/audiobooks/ximalaya.py) ，仅核对公开搜索、目录与免费章节接口，未引入其付费解析、第三方服务或解密逻辑。
