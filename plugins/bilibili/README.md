# bilibili 视频音频插件

源码位于 `src/index.js`，使用上级 `npm run build` 生成独立的 `dist/plugin.js`，运行时只使用 MusicFree 内置 Axios。

支持视频搜索、独立音频流、详情和单视频导入。输入支持 BV 号、`BV号:分P`，或 `https://www.bilibili.com/video/BV号?p=2` 链接。身份为 `BV号:分P`，获取音频时重新解析该分 P 的 CID，不能找不到时回退第一 P。`b23.tv` 短链接需先展开。

搜索使用匿名设备标识，不读取用户浏览器 Cookie。播放返回独立音频轨及必要 Referer，不把视频混合流或预览当作完整音频。

支持「专辑」搜索：输入「林俊杰」等关键词，视频作为专辑结果，打开后完整展开该视频的全部分 P。分 P 保留各自的 BV、页码、CID、时长和封面；缺失、重复或顺序异常时整次失败。这是视频合集展示，不是唱片目录；单 P 长视频不会自动切歌，也不展开跨视频的 UP 主合集。课堂推广条目不会混入视频结果。

视频没有原生歌曲歌词，`getLyric` 明确返回无歌词；字幕不是歌曲歌词。当前不实现标题搜索匹配其他平台歌词，以免错配版本。暂不支持 AU 音频区、AV 号、收藏夹导入和登录。

安装和验证命令见上级 `README.md`。
